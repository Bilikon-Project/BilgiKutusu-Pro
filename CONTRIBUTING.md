# BilgiKutusu Pro'ya Katkıda Bulunma

BilgiKutusu Pro, internet bağlantısı olmadan bilgi kaynaklarına erişimi kolaylaştırmayı amaçlayan açık kaynaklı bir projedir.

## Katkı süreci

1. Hata veya öneri için GitHub'da bir Issue açın.
2. Depoyu fork edin ve değişikliklerinizi ayrı bir dalda hazırlayın.
3. İlgili betikleri ve web arayüzünü test edin.
4. Değişikliklerin amacını, test adımlarını ve varsa ekran görüntülerini içeren bir Pull Request gönderin.

## Katkı ilkeleri

- Katkılarınızın size ait olduğundan veya paylaşım iznine sahip olduğunuzdan emin olun.
- Telifli kitap, video, harita veya diğer dosyaları dağıtım izni olmadan eklemeyin.
- Parola, API anahtarı, kişisel bilgi veya gerçek ağ kimlik bilgilerini depoya eklemeyin.
- Donanım ve ağ yapılandırmalarını değiştiren komutları açıkça belgeleyin; mümkünse varsayılan olarak salt okunur tutun.
- Değişiklikleri mümkün olduğunca küçük, anlaşılır ve belgeli tutun.
- Projenin odağı çevrimdışı bilgi erişimidir. Yapay zekâ bileşenleri mevcut kapsamın dışındadır.

## Lisans

Katkı gönderenler, katkılarını `LICENSE` dosyasındaki MIT Lisansı koşullarıyla yayımlamaya yetkili olduklarını kabul eder. MIT Lisansı ticari kullanıma da izin verir; katkı sahiplerinin telif hakları saklıdır.
